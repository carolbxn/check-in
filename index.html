Limpar testes

O armazenamento do navegador pode ser perdido ao limpar dados do site ou remover o aplicativo. Faça backups criptografados frequentemente e teste a restauração. Os registros no navegador não são criptografados por senha pelo próprio app; use senha/biometria no dispositivo. O PWA não sincroniza automaticamente entre Mac e iPhone.

Instruções e segurança

Guia de uso do diário no iPhone do seu marido. Tudo permanece no aparelho até ele exportar um backup.

1. Registro diário

Use Alimentação, Sintomas (pode marcar vários), Evacuações (Bristol 1–7) e Contexto. Confira os alimentos reconhecidos automaticamente. Use o microfone do teclado do iPhone para ditar.

2. Backup semanal — indispensável

  1. Abra Meus dados → Exportar backup criptografado.
  2. Digite uma senha de pelo menos 12 caracteres, que vocês consigam guardar em local seguro.
  3. Toque em Gerar backup. O app verifica internamente que os dados gerados podem ser descriptografados.
  4. No iPhone, use Compartilhar/Arquivos conforme aparecer e salve o arquivo .mdi na pasta escolhida do iCloud Drive ou outra mídia segura.
  5. Abra o app Arquivos, confirme que o arquivo existe e tem tamanho diferente de zero; depois retorne ao diário e toque em Confirmei que salvei o arquivo.
  6. Periodicamente transfira uma cópia ao MacBook e teste a restauração num navegador/dispositivo de teste, sem apagar o banco principal.

A confirmação é manual: o navegador não tem permissão para garantir que o arquivo foi guardado no iCloud Drive. O lembrete aparece ao abrir o app, não como notificação automática em segundo plano.

3. Restaurar no iPhone ou Mac

  1. Abra Meus dados → Importar backup.
  2. Selecione o arquivo .mdi em Arquivos e digite a senha.
  3. Revise a confirmação antes de importar. Registros com o mesmo ID poderão ser atualizados.
  4. Confira no histórico se a restauração funcionou.

Faça testes com dados fictícios. Nunca apague os dados originais antes de testar a cópia.

4. Instalar no iPhone dele

  1. Hospede somente os arquivos estáticos do aplicativo numa página HTTPS gratuita (nunca envie arquivos .mdi ou .ics).
  2. No Safari do iPhone dele, abra o endereço HTTPS.
  3. Toque em Compartilhar → Adicionar à Tela de Início → Adicionar.
  4. Abra pelo ícone, registre um dado fictício e teste a exportação e restauração.

O app no Mac e o app no iPhone têm armazenamentos diferentes. A troca de dados é manual por backup criptografado.

5. Importar calendário no Mac

Exporte o calendário compartilhado autorizado como arquivo .ics no Calendário do macOS. Abra o diário no Mac e use Meus dados → Importar histórico do Calendário. Selecione e revise os eventos antes de importar. Depois gere um backup criptografado e transfira para o iPhone.

6. Privacidade, custos e limitações

Sem servidor de registros, sem conta e sem API paga. O conteúdo do banco local do navegador não tem criptografia própria. Proteja o iPhone com senha/biometria e mantenha uma cópia segura fora dele. O iCloud gratuito depende do espaço disponível na conta. Se limpar os dados do Safari/PWA, você pode perder todo o histórico local. Uma cópia de arquivo não é sincronização automática.
